# Online Retail Order Management System (OMS)

**Business Analysis | SQL | Power BI | Retail & E-commerce**

## Project Overview

This portfolio project explores how an Online Retail Order Management System can be improved through business analysis, SQL-based investigation, and Power BI reporting.

The project focuses on order processing, shipping performance, delivery delays, cancelled orders, and geographic order distribution. It aims to identify operational issues and translate findings into practical system-enhancement recommendations.

## Business Problem

Retail order management involves multiple operational activities, from order placement to shipment and delivery. Delays, inconsistent shipment information, and limited visibility into order performance can make it difficult to identify process bottlenecks and prioritize improvements.

This project investigates these challenges using an e-commerce dataset and proposes potential improvements to order tracking, shipment monitoring, and operational reporting.

## Project Objectives

- Analyze order volumes and shipping performance.
- Identify delivery delays and cancelled orders.
- Compare scheduled shipping time with actual shipping time.
- Explore order distribution across geographic locations.
- Develop recommendations for improving order visibility and operational monitoring.
- Translate business needs into potential system enhancements and reporting requirements.

## Tools & Technologies

- **SQL:** Data analysis and business-focused queries
- **Power BI:** Interactive dashboard and KPI reporting
- **Excel / CSV:** Dataset review and preparation
- **Business Analysis:** Problem definition, requirements, process improvement, and recommendations

## Key Analysis Areas

1. Order volume and distribution
2. On-time, late, and cancelled deliveries
3. Scheduled versus actual shipping performance
4. Shipping performance by shipping type
5. Geographic distribution of orders
6. Operational improvement opportunities

The project is intended to demonstrate business analysis through:

## Expected Business Value

The proposed improvements aim to help retail operations teams:

- Identify shipping delays and delivery exceptions.
- Improve visibility into order and shipment status.
- Monitor operational KPIs consistently.
- Investigate performance differences across shipping methods and regions.
- Prioritize process and system enhancements based on data.

These are proposed benefits, not measured business outcomes.

## Dataset & Disclaimer

This project uses a public e-commerce dataset for portfolio and learning purposes. The analysis reflects the available dataset and its limitations; it does not represent the actual performance of a specific retailer.

The dataset may contain inconsistencies in dates and shipment-related fields. Findings and recommendations should therefore be interpreted in context and validated before being used for operational decisions.
